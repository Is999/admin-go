## 3. 统一返回结构

所有接口统一返回：

```json
{
  "status": true,
  "code": 1,
  "message": "成功",
  "data": {}
}
```

## 4. 公共约束

- 接口返回 trigger 或入队成功，只代表任务系统接受请求，不代表业务任务或工作流已经完成。
- `taskId` 标识单个队列任务，`workflowId` 标识一次 DAG 实例；联调和排障必须同时保留实际 `queue`。
- `processAt`、`deadline` 必须为 RFC3339 时间格式。
- `processAt` 和 `processInSeconds` 不能同时设置。
- `uniqueTTLSeconds`、`timeoutSeconds` 必须大于 `0`。
- `retry` 范围为 `0-25`，`timeoutSeconds` 范围为 `1-86400`。
- 任务系统未启用时，接口会返回任务系统未开启类错误。
- 重跑仅适用于仍在 archived 集合中的精确任务；不能证明幂等时应使用领域补偿入口。

## 5. 响应字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| status | bool | 是 | false | 状态: true 成功, false 失败 |
| code | int | 是 | 1 | 业务状态码 |
| message | string | 否 |  | 消息 |
| data | object/array/null | 否 |  | 任务接口返回数据，不同接口结构不同 |
