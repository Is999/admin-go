# 用户标签接口总览

## 1. 文档说明

用户标签接口当前服务于框架骨架，负责验证工作流编排和释放互斥锁。默认实现不内置具体标签规则，主工作流只接受 `dryRun=true`；非 dry-run 请求会在任何清表、切表操作前失败关闭。

页面操作、参数选择和验收证据见[用户标签操作与验收手册](功能模块/用户标签/用户标签操作手册.md)；DAG、分片、表、租约和 outbox 见[用户标签架构与扩展指南](功能模块/用户标签/用户标签实现与调度说明.md)；异常恢复见[任务系统与用户标签故障处置手册](功能模块/用户标签/任务系统与用户标签排障手册.md)。

- “用户标签工作流接口”负责 `full / delta / targeted / recalculate` 模式触发。
- “指定标签重算接口”负责触发指定标签重算工作流。
- “内网接口”负责受信任服务免 JWT 调用，但仍执行 Ops HMAC、nonce 防重放和内网来源校验。

## 2. 文档导航

| 功能       | 说明                                             | 文档                                               |
|----------|------------------------------------------------|--------------------------------------------------|
| 用户标签工作流  | 手工触发 `full / delta / targeted / recalculate`   | [用户标签工作流接口](接口文档/用户标签/用户标签工作流接口.md)              |
| 工作流互斥锁释放 | 在确认异常工作流已终止后，按 `workflowId + mode` 精确释放用户标签互斥锁 | [用户标签工作流接口](接口文档/用户标签/用户标签工作流接口.md#8-工作流互斥锁释放入口) |
| 指定标签重算   | 触发 `recalculate` 骨架工作流                         | [指定标签重算接口](接口文档/用户标签/指定标签重算接口.md)                |
| 内网接口     | 免 JWT 的内网联动入口                                  | [内网接口](接口文档/用户标签/内网接口.md)                        |

接口选择原则：

- 后台通用表单使用 `POST /api/user-tags/workflows`，字段采用 camelCase。
- 指定标签重算表单使用 `POST /api/user-tags/recalculations`，字段采用 snake_case，并转换为 `recalculate` workflow。
- 服务间调用使用对应 `/internal/user-tags/...` 入口，免 JWT 但必须通过私网来源、Ops HMAC、时间窗口、Redis nonce；生产跨主机使用 mTLS。
- 只有确认原 full workflow 已终止、没有 active 节点且 owner 精确匹配时，才使用租约释放接口。

## 3. 模式速览

| 模式 | 说明 |
| --- | --- |
| `full` | 全量骨架链路，包含结果表准备和提交。 |
| `delta` | 增量骨架链路，复用主 DAG。 |
| `targeted` | 指定 UID 的骨架链路，要求传入 `uids` 和 `tagTypes`。 |
| `recalculate` | 指定 `tagTypes` 的骨架链路。 |

四种模式当前都必须 `dryRun=true`。工作流成功只证明 trigger、DAG、表和锁边界可用，不能作为正式标签结果验收结论。

## 4. 响应字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| status | bool | 是 | false | 状态: true 成功, false 失败 |
| code | int | 是 | 1 | 响应状态码 |
| message | string | 否 |  | 消息 |
| data | object/array/null | 否 |  | 用户标签工作流触发结果或重算结果 |
